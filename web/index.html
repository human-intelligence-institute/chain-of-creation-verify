How this works · what each check proves ›

A creator certifies a work; that certification is written to a public, append-only transparency log. This page verifies four things independently, in your browser:

Signature — the record is cryptographically signed. Published — the record is actually committed in the public log (not just shown to you). Identity — the signing key resolves to a real creator. Your file — a file you hold matches the certified work, exactly or as a consistent copy.

The WebAssembly verifier and the trust anchors are part of this page, not supplied by the server — so the answer can’t be faked by whoever sent you here.
